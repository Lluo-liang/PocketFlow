## 🚀 使用流程

### 1️⃣ 开始新任务

**步骤1: 复制模板文件夹**
```bash
# 复制模板到tasks目录下,并重命名为: PLM编号-功能简述
cp -r .claude/mydocs/_TEMPLATE-任务模板 .claude/mydocs/tasks/PLM-338429-引流活动商品列表
```

**步骤2: 调用 Skill 1 生成PRD**
```
使用 soms-requirement-analysis Skill,输入需求内容,自动填充任务文档
```

**步骤3: 检查PRD完整性**
- 确认 6 个文档都已填写完整
- 确认知识库引用正确
- 确认实现方案可行

---

### 2️⃣ 实现代码

**步骤1: 调用 Skill 2 实现代码**
```
使用 soms-code-implementation-v2 Skill,指定任务文件夹路径,自动生成代码
```

**步骤2: 检查实现问题记录**
- 查看 `99-实现问题记录.md`
- 根据问题记录更新PRD或知识库

---

### 3️⃣ 维护知识库

**自动更新(推荐)**:
- Skill 1 执行时,会识别通用规范并询问是否写入知识库
- Skill 2 执行时,会在问题记录中标记"是否需要更新知识库"

**手动更新**:
1. 在 `knowledge-base/` 对应分类下创建 `.md` 文件
2. 手动更新 `knowledge-index.json` (或请求 Skill 帮助更新)

## 📚 知识库索引使用

### 检索知识库
```bash
# Skill 会自动读取 knowledge-index.json 进行检索
# 你也可以手动搜索关键词:
cat .claude/mydocs/knowledge-index.json | jq '.searchIndex.keywords'
```

### 更新索引
知识库索引由 Skill 自动维护,每次添加新文件时会更新:
- `keywords`: 关键词索引
- `tags`: 标签索引
- `files`: 文件列表

## ❓ 常见问题

### Q: 如何快速找到相关知识库文件?
A: 使用 Skill 时会自动检索,或手动查看 `knowledge-index.json` 的 `searchIndex`

### Q: 任务完成后,文档要删除吗?
A: 不需要,建议保留供后续参考

### Q: 知识库文件太多,如何管理?
A: 按照分类目录存放,使用索引文件快速检索

### Q: 如何更新知识库索引?
A: Skill 会自动维护,手动添加文件后可请求 Skill 更新索引
