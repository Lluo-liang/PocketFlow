## 第一步：配置 LLM（必须）

选择你想用的 LLM 提供商，设置 API Key：

### 选项 1：OpenAI（推荐 GPT-4）

```bash
export OPENAI_API_KEY="sk-..."
```

然后编辑 `learning-explainer/utils/call_llm.py`，取消注释 OpenAI 部分：

```python
def call_llm(prompt: str, system_prompt: str = None) -> str:
    from openai import OpenAI
    client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))
    messages = []
    if system_prompt:
        messages.append({"role": "system", "content": system_prompt})
    messages.append({"role": "user", "content": prompt})
    response = client.chat.completions.create(
        model="gpt-4",
        messages=messages
    )
    return response.choices[0].message.content
```

## 技能开发最佳实践

### 1. 遵循 Agentic Coding 流程

创建新技能时：

```
1. 写 docs/design.md：
   - 描述需求
   - 设计流程图
   - 定义节点

2. 实现 utils/：
   - 创建工具函数
   - 测试每个工具

3. 实现 nodes.py：
   - 每个节点一个类
   - prep-exec-post 清晰分离

4. 实现 flow.py：
   - 连接节点
   - 定义流程

5. 实现 main.py：
   - 用户交互
   - 运行流程
```

### 2. 保持简单

```python
# ✅ 好的节点设计
class SimpleNode(Node):
    def prep(self, shared):
        return shared["data"]  # 只读取

    def exec(self, data):
        return process(data)   # 只计算

    def post(self, shared, prep_res, exec_res):
        shared["result"] = exec_res  # 只写入
```

### 3. 善用设计模式

- **Workflow**：线性任务分解（如讲解器）
- **Agent**：需要动态决策（如智能调试）
- **Batch**：批量处理（如批量分析多个文件）
- **RAG**：需要检索知识（如文档问答）

## 常见问题

### Q1: LLM 调用失败？

检查：
1. API Key 是否正确设置：`echo $OPENAI_API_KEY`
2. 网络是否可访问 API
3. `utils/call_llm.py` 是否正确配置

### Q2: 如何调试节点？

在节点中添加打印：
```python
def exec(self, data):
    print(f"DEBUG: 输入数据 = {data}")
    result = process(data)
    print(f"DEBUG: 输出结果 = {result}")
    return result
```

### Q3: 如何复用工具函数？

所有技能共享同一个 LLM 调用工具：
```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent.parent / "learning-explainer"))
from utils.call_llm import call_llm
```

### Q4: 技能运行太慢？

1. 减少 LLM 调用次数
2. 使用更快的模型（如 GPT-3.5、Gemini Flash）
3. 使用 AsyncNode 并行调用
