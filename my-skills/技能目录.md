# 🎯 PocketFlow 个人技能目录

这是你的个人 AI 技能工具箱，用 PocketFlow 构建，辅助学习和编程。

## 📚 当前可用技能

### 1. 概念深度讲解器 (learning-explainer)

**功能**：深入讲解编程概念，从"是什么、为什么、怎么用"三个角度

**使用**：
```bash
cd learning-explainer
python main.py "Python装饰器"
```

**适用场景**：
- ✅ 遇到不懂的新概念
- ✅ 复习已学知识
- ✅ 准备技术面试
- ✅ 理解框架原理

**设计模式**：Workflow（线性工作流，5个节点）

---

### 2. 代码学习审查器 (code-reviewer)

**功能**：分析代码的工作原理、设计思路，帮助理解代码

**使用**：
```bash
cd code-reviewer
python main.py path/to/code.py
python main.py --stdin  # 从剪贴板
```

**适用场景**：
- ✅ 阅读开源项目源码
- ✅ 学习优秀代码实现
- ✅ Code Review 学习
- ✅ 理解框架内部实现

**设计模式**：单节点（可扩展为多节点流程）

---

### 3. 编程练习生成器 (practice-generator)

**功能**：根据主题生成渐进式练习题，边学边练

**使用**：
```bash
cd practice-generator
python main.py "二叉树遍历"
python main.py "SQL查询" --difficulty hard --count 5
```

**适用场景**：
- ✅ 学完概念后巩固练习
- ✅ 准备面试刷题
- ✅ 系统学习某个专题
- ✅ 自我测试理解程度

**设计模式**：单节点（可扩展为验证流程）

## 🎓 推荐学习工作流

### 完整学习循环

```bash
# 1️⃣ 学习概念
cd learning-explainer
```

## 🛠️ 技能开发指南

### 创建新技能的步骤

1. **规划设计**：
   ```bash
   mkdir my-new-skill
   cd my-new-skill
   mkdir utils docs
   touch docs/design.md
   ```

2. **编写设计文档**（docs/design.md）：
   - 需求描述
   - 流程设计（画 Mermaid 图）
   - 节点设计（prep/exec/post）
   - 数据结构（shared store）

3. **实现工具函数**（utils/）：
   ```bash
   # 复用现有的 LLM 调用
   ln -s ../../learning-explainer/utils/call_llm.py utils/
   ```

4. **实现节点**（nodes.py）：
   ```python
   from pocketflow import Node

   class MyNode(Node):
       def prep(self, shared):
           return shared["input"]

       def exec(self, data):
           return process(data)

       def post(self, shared, prep_res, exec_res):
           shared["output"] = exec_res
   ```

5. **定义流程**（flow.py）：
   ```python
   from pocketflow import Flow
   from nodes import MyNode

   def create_flow():
       node = MyNode()
       return Flow(start=node)
   ```

6. **编写入口**（main.py）：
   ```python
   from flow import create_flow

   shared = {"input": "..."}
   flow = create_flow()
   flow.run(shared)
   ```

## 🎯 技能开发最佳实践

### 1. 遵循 Agentic Coding 原则
- 先写设计文档，再写代码
- 保持节点职责单一
- 善用 PocketFlow 的设计模式

### 2. 代码组织
```
my-skill/
├── docs/
│   └── design.md       # 设计文档（必须）
├── utils/
│   └── *.py            # 工具函数
├── nodes.py            # 节点定义
├── flow.py             # 流程定义
├── main.py             # 入口程序
├── requirements.txt    # 依赖
└── README.md           # 说明文档
```

### 3. 测试技能
```bash
# 简单测试
python main.py [测试输入]

# 如果是复杂流程，可以写单元测试
python -m pytest test_skill.py
```

### 4. 复用 vs 重写
- ✅ 复用 `utils/call_llm.py`
- ✅ 参考现有技能的结构
- ⚠️ 不要过度抽象
- ⚠️ 简单够用就好

## ❓ 常见问题

### Q: 技能之间如何共享数据？
A: 通过文件系统。一个技能生成 Markdown，另一个技能读取处理。

### Q: 可以组合多个技能吗？
A: 可以！写一个 shell 脚本串联多个技能：
```bash
#!/bin/bash
cd learning-explainer && python main.py "$1" > temp.md
cd ../code-reviewer && python main.py temp.md
```

### Q: 技能运行太慢怎么办？
A:
1. 使用更快的模型（GPT-3.5、Gemini Flash）
2. 使用 AsyncNode 并行调用
3. 减少 LLM 调用次数

### Q: 如何调试技能？
A: 在节点中添加 print，或使用 PocketFlow 的可视化工具（见 cookbook/pocketflow-tracing）
