## ⚡ 60秒快速开始

### 1️⃣ 安装和配置（一次性）

```bash
# 进入技能目录
cd /Users/80892291/WorkSpace/IDEA/pocketflow/PocketFlow/my-skills

# 运行自动设置脚本
./setup.sh

# 配置 LLM API Key（三选一）
export OPENAI_API_KEY="sk-..."        # OpenAI
# 或
export ANTHROPIC_API_KEY="sk-ant-..."  # Claude
# 或
export GEMINI_API_KEY="..."            # Gemini

# 编辑 LLM 配置文件
vim learning-explainer/utils/call_llm.py
# 取消注释你选择的 LLM 代码
```

### 2️⃣ 测试技能

```bash
# 测试概念讲解器
cd learning-explainer
python main.py "Python装饰器"

# 如果看到详细的讲解内容，说明成功了！✅
```

### 3️⃣ 设置便捷别名（可选但推荐）

```bash
# 加载别名
source ../aliases.sh

# 或永久添加到你的 shell 配置
echo "source $(pwd)/../aliases.sh" >> ~/.zshrc

# 然后就可以直接用：
explain "闭包"
review mycode.py
practice "二叉树" -d medium
```

## 🎓 三个核心技能

### 💡 概念讲解器 - 深入理解概念

**什么时候用**：遇到不懂的编程概念

**怎么用**：
```bash
cd learning-explainer
python main.py "你想学的概念"

# 示例
python main.py "Python装饰器"
python main.py "闭包"
python main.py "依赖注入"
python main.py "红黑树"
```

**你会得到**：
- ✅ 是什么、为什么、怎么用三角度讲解
- ✅ 生动的生活类比
- ✅ 实际代码示例
- ✅ 学习路径和练习建议
- ✅ 常见误区提醒

---

### 🔍 代码审查器 - 理解代码原理

**什么时候用**：想理解某段代码如何工作

**怎么用**：
```bash
cd code-reviewer
python main.py path/to/code.py

# 从剪贴板分析
pbpaste | python main.py --stdin

# 分析 PocketFlow 核心代码
python main.py ../../pocketflow/__init__.py
```

**你会得到**：
- ✅ 代码功能概述
- ✅ 关键概念解析
- ✅ 结构分析
- ✅ 工作原理详解
- ✅ 改进建议

---

### 📝 练习生成器 - 巩固学习

**什么时候用**：学完概念想做练习

**怎么用**：
```bash
cd practice-generator
python main.py "主题"
python main.py "主题" --difficulty hard
python main.py "主题" -d easy -c 5

# 示例
python main.py "Python列表推导式"
python main.py "二叉树遍历" -d hard
python main.py "SQL查询" -c 5
```

**你会得到**：
- ✅ 3-5道渐进式练习题
- ✅ 每题有输入输出示例
- ✅ 思考提示
- ✅ 详细答案（带注释）
- ✅ 知识点总结

---

## 🔄 完整学习循环示例

假设你要学习"Python装饰器"：

```bash
# 步骤1：理解概念
cd learning-explainer
python main.py "Python装饰器"
# 阅读输出，理解是什么、为什么、怎么用

# 步骤2：做基础练习
cd ../practice-generator
python main.py "Python装饰器" -d easy
# 保存输出，尝试完成练习

# 步骤3：写代码实现
# 在编辑器中完成练习，保存为 my_decorator.py

# 步骤4：审查自己的代码
cd ../code-reviewer
python main.py my_decorator.py
# 看看有哪些可以改进的地方

# 步骤5：提升难度
cd ../practice-generator
python main.py "Python装饰器" -d medium
# 继续练习，巩固理解

# 步骤6：高级挑战
python main.py "Python装饰器" -d hard
# 深入掌握
```

## 💡 使用技巧

```bash

```

### 技巧3：阅读源码

```bash

cd code-reviewer
python main.py path/to/interesting/code.py

# 如果有不懂的概念
cd ../learning-explainer
python main.py "不懂的概念"
```

### 技巧4：建立知识库

```bash

# 用 Markdown 编辑器查看更美观
```

```bash
echo $OPENAI_API_KEY

# 检查配置
cat learning-explainer/utils/call_llm.py

# 测试 LLM
cd learning-explainer/utils
python call_llm.py
```

