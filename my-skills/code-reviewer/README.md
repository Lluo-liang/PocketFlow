# 🔍 代码学习审查器

一个帮助你理解代码工作原理的智能助手。

## 功能特点

✅ **功能概述**：快速理解代码做什么
✅ **概念解析**：识别并解释关键编程概念
✅ **结构分析**：理解代码的组织方式
✅ **亮点提炼**：学习优秀的实现方式
✅ **原理详解**：深入理解代码如何工作
✅ **知识图谱**：了解需要掌握的前置知识
✅ **改进建议**：发现学习机会
✅ **延伸学习**：获取相关学习资源

## 使用方法

### 分析文件
```bash
python main.py path/to/your/code.py
```

### 从剪贴板分析
```bash
pbpaste | python main.py --stdin
```

### 分析 PocketFlow 核心代码示例
```bash
python main.py ../../pocketflow/__init__.py
```

## 使用场景

- 📖 阅读开源项目源码时
- 🎓 学习他人的优秀代码
- 💡 理解框架/库的实现原理
- 🔍 Code Review 时学习同事的代码
- 🎯 准备技术面试，理解经典代码

## 扩展建议

可以改造成 PocketFlow 的多节点流程：
1. **代码解析节点**：分析代码结构
2. **概念提取节点**：识别关键概念
3. **质量评估节点**：评估代码质量
4. **改进建议节点**：生成具体建议
5. **格式化节点**：生成报告
