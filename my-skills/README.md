# 我的 PocketFlow 技能集

这个目录包含我个人的学习和编程辅助技能。

## 技能列表

### 1. 学习助手类
- `learning-explainer/` - 概念深度讲解器（把复杂概念讲明白）
- `code-reviewer/` - 代码学习审查器（帮助理解代码原理）
- `practice-generator/` - 练习题生成器（根据学习内容生成练习）

### 2. 编程助手类
- `bug-detective/` - Bug 调查侦探（分析错误并提供解决方案）
- `code-optimizer/` - 代码优化建议器（提供改进建议）
- `doc-generator/` - 文档生成器（为代码生成注释和文档）

## 使用方法

```bash
# 进入某个技能目录
cd learning-explainer

# 运行技能
python main.py
```
